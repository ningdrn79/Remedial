# 🤖 Website EduCode AI - Portal Remedial Coding & AI
### SDS Cinta Kasih Tzu Chi • Koding & Kecerdasan Artifisial (Mid Semester 1 TP 2026/2027)

Portal web interaktif, edukatif, dan ramah anak dengan tema **"Welcome to Coding and AI"** yang dirancang khusus untuk pembelajaran dan evaluasi remedial siswa Sekolah Dasar (SD).

---

## 🌟 Fitur Utama Website

### 1. 🎈 Antarmuka Ceria, Interaktif & Edukatif
- **Mentor Koding & AI**: Foto Ibu Guru **Darningsih, S.T.** di Laboratorium Koding & AI modern dengan bingkai bercahaya (*glow frame*) dan pesan sambutan yang hangat.
- **Efek Audio Sintetis**: Suara *pop*, *correct*, *wrong*, dan *fanfare* ceria berbasis Web Audio API tanpa perlu file eksternal.
- **Selebrasi Confetti**: Pesta confetti semarak (*canvas-confetti*) saat anak menyelesaikan soal remedial.
- **Kata Perenungan Master Cheng Yen**: Mengedepankan nilai budi pekerti, kejujuran, dan ketulusan hati.

### 2. 📝 Sistem Evaluasi Remedial Kelas 4 (Mid Semester 1)
- **Mode Layar Penuh & Timer Aktif 60 Menit**:
  - Timer hitung mundur 60 menit dengan indikator visual dan peringatan otomatis.
- **Form Identitas Siswa**:
  - Input Nama Lengkap, Nomor Absen, Pilihan Kelas (**4A, 4B, 4C, 4D, 4E**), dan Nilai Awal.
- **10 Soal Pilihan Ganda**:
  - Materi Microsoft Excel (Row, Column, Cell, SUM, AVERAGE, Autofill) dan Kecerdasan Artifisial (Perplexity AI).
- **5 Soal Uraian Mandiri**:
  1. Pengertian rumus `=AVERAGE()`
  2. Pengertian rumus `=SUM()`
  3. Pengertian rumus `=COUNT()`
  4. Fungsi penunjuk mouse tanda tambah hitam tipis (*Autofill*)
  5. Penulisan rumus tabel hewan (sel E9 `=SUM`, sel E10 `=AVERAGE`, sel E11 `=COUNT`)
- **Tampilan Selesai Mengerjakan**:
  - Hanya menampilkan **Skor Akhir berukuran besar**, status kelulusan, dan kata-kata motivasi yang hangat tanpa kunci jawaban agar anak termotivasi.
  - Tombol unduh laporan hasil remedial siswa berupa file PDF resmi.

### 3. 🔒 Fitur Tersembunyi: Panel Khusus Guru (Teacher Portal)
Untuk menjaga privasi dan fokus anak-anak di halaman utama, daftar rekap nilai **tidak lagi ditampilkan di halaman depan publik siswa**, melainkan berada di fitur tersendiri yang tersembunyi (*discreet*):
- **Akses Masuk Guru**:
  - Tombol elegan `[ 🔒 Panel Guru ]` di navigasi atas (Navbar).
- **Fitur di Dalam Panel Guru**:
  - **Filter Kelas Cepat**: Tab filter Semua Kelas, 4A, 4B, 4C, 4D, 4E.
  - **Pencarian Langsung (Live Search)**: Berdasarkan nama anak atau nomor absen.
  - **Metrik Statistik Real-Time**: Total siswa, nilai rata-rata, nilai tertinggi, dan tingkat ketuntasan KKM (70).
  - **📥 Unduh PDF Hasil Score, Jawaban Siswa & Keterangan Lengkap**:
    - Tombol khusus di setiap baris siswa untuk mencetak PDF A4 resmi yang memuat Kop SDS Cinta Kasih Tzu Chi, Identitas Siswa, Rekap Nilai, **Rincian Jawaban Siswa**, **Score per Soal**, dan **Keterangan Pembahasan/Evaluasi**, serta tanda tangan resmi **Darningsih, S.T.** dan Orang Tua Siswa.
  - **👁️ Lihat Jawaban (Quick Preview)**:
    - Membaca lembar jawaban siswa beserta score dan keterangannya langsung di layar secara interaktif.
  - **📊 Unduh Rekap Excel (CSV)**:
    - Tombol unduh seluruh data nilai rekap siswa ke dalam format file spreadsheet Excel/CSV bertanda tangan UTF-8 BOM.

## 🚀 Cara Menjalankan Website
1. Buka folder `d:/Erapot/` di file explorer.
2. Klik ganda pada file `index.html` untuk langsung membukanya di browser apa saja (Google Chrome, Microsoft Edge, Firefox, Safari).
3. Selesai! Semua fitur langsung dapat digunakan secara interaktif tanpa server lokal.
